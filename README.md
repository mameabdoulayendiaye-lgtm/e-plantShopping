# e-plantShopping

## Nom du dépôt
*e-plantShopping*

## Nom du projet
e-plantShopping — Boutique en ligne de plantes

## Aperçu de l'application
*e-plantShopping* est une application web de commerce électronique dédiée à la vente de plantes d'intérieur et d'extérieur. Les utilisateurs peuvent parcourir un catalogue de plantes, consulter les détails de chaque produit, ajouter des articles à un panier et visualiser le total de leur commande. L'interface est simple, moderne et responsive.
